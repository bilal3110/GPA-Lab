# GPA Lab - Academic Performance Tool

GPA Lab is a comprehensive, web-based academic tool designed to help students track and manage their academic performance. It features a modern, responsive interface with multiple calculators for GPA, CGPA, and attendance tracking.

## 🚀 Features

- **CGPA Calculator**: Calculate your Cumulative Grade Point Average across multiple semesters.
- **GPA Calculator**: Determine your Grade Point Average for a single semester based on course grades and credit hours.
- **Grade to CGPA**: Easily convert letter grades directly to CGPA.
- **Attendance Calculator**: 
  - Calculate current attendance percentage.
  - Determine the number of classes needed to reach a target attendance percentage.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Modern UI**: A responsive, warm paper-and-forest-green interface designed for comfortable academic use.

## 🛠️ Built With

- **HTML5**: For semantic structure.
- **Vanilla CSS3**: Custom styling with centralized Field Notes color tokens, automatic light/dark palettes, and responsive layouts.
- **JavaScript (ES6+)**: Dynamic calculations and DOM manipulation.

## 🖥️ Getting Started

1. Clone the repository or download the source code.
2. Open `index.html` in any modern web browser.
3. Switch between tabs to use the different calculators.

## 📝 Usage

### GPA/CGPA Calculation
1. Select the relevant tab (CGPA, GPA, or Grade to CGPA).
2. Add your semesters or courses using the "Add" buttons.
3. Enter your grades/GPAs and credit hours.
4. Click "Calculate" to see your results in a detailed result card.

### Attendance Tracking
- **Percentage**: Enter total classes and attended classes to see your current percentage.
- **Target**: Enter your current percentage, target percentage, and total classes so far to find out how many more classes you need to attend.
